# PWA 图标目录

请将以下尺寸的 PNG 图标文件放置在此目录中：

| 文件名        | 尺寸       | 用途              |
|---------------|------------|-------------------|
| icon-72.png   | 72×72 px   | Android 旧设备    |
| icon-96.png   | 96×96 px   | Android           |
| icon-128.png  | 128×128 px | Chrome Web Store  |
| icon-144.png  | 144×144 px | Windows / IE      |
| icon-152.png  | 152×152 px | iOS               |
| icon-192.png  | 192×192 px | Android / PWA 必需（含 maskable）|
| icon-384.png  | 384×384 px | Android           |
| icon-512.png  | 512×512 px | PWA 必需（含 maskable）|

## 生成方式

可以使用 PWABuilder 官网的图标生成工具：
https://www.pwabuilder.com/imageGenerator

上传一张 512×512 或更大的原始 PNG 图，即可自动生成所有尺寸。
